`source-snapshots/` 保存原有方案 Markdown 与两个 skill 的本机当前文件副本。历史方案与 skill 不会因本次对话自动更新；以本包明确的修正与适用范围理解它们，不能把整理稿误认为 skill 已安装新版本。

`manifest.json` 列出文件大小与 SHA-256。压缩包不包含账号配置、密钥、外部项目代码、完整聊天记录、网页实际交付素材或页面验证截图。
