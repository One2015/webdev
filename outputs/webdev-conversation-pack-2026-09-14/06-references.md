# 研究与资料索引

这些来源在此前对话中已检索。本次打包不代表重新全文复核或下载论文；链接可用于后续阅读。

| 来源 | 作用与边界 |
|---|---|
| [DesignScape, CHI 2015](https://www.dgp.toronto.edu/~donovan/design/designscape.pdf) | 布局探索与局部优化；不等于完整网页风格分类 |
| [Scout, CHI 2020](https://arxiv.org/abs/2001.05424) | 用语义结构、顺序、强调等高层约束探索不同界面布局 |
| [MAP-Elites, 2015](https://arxiv.org/abs/1504.04909) | 在不同特征区域保留高质量方案；原实验非网页 |
| [DPP, 2012](https://arxiv.org/abs/1207.6083) | 从候选中选择兼顾质量和低重复的集合；相似度定义仍需设计 |
| [Webzeitgeist, CHI 2013](https://hci.stanford.edu/publications/2013/Webzeitgeist/webzeitgeist.pdf) | 采集 DOM、渲染结构和视觉属性进行设计挖掘 |
| [Parallel Prototyping, TOCHI 2010](https://hci.stanford.edu/publications/2010/parallel-prototyping/ParallelPrototyping2010-final.pdf) | 广告设计任务中的平行探索研究；不证明十个网页最优 |
| [Design2Code](https://arxiv.org/abs/2403.03163) | 截图到代码评估，与创意多样性不同 |
| [DTCG Format 2025.10](https://www.w3.org/community/reports/design-tokens/CG-FINAL-format-20251028/) | Token 交换规范；社区组报告，非 W3C 正式标准 |
| [USWDS Tokens](https://designsystem.digital.gov/design-tokens/) | 颜色、字体、间距等设计参数组织 |
| [NN/g Minimalism](https://www.nngroup.com/articles/characteristics-minimalism/) | 将极简拆成多种可观察特征 |
| [NN/g Mood Boards](https://www.nngroup.com/articles/mood-boards/) | 建立与沟通整体视觉方向 |

本对话没有找到每品类固定风格数量的公认标准。数量、距离阈值、预算及家族分类都是需要实际校准的项目规则。
