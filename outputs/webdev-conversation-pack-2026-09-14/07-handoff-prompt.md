# 新对话续接 Prompt

可把下面内容与整个资料包交给新的模型对话：

```text
这是 Webdev 参考驱动设计与多样性生成项目的续接资料包。
请先读 README、01-context-and-decisions、02-pipeline、05-gates-and-rubrics，按需读其余文档。

我的目标是从参考提取骨架、模块、组件、状态、视觉与素材信息，快速重组成同品类但明显不同的网页。重点不是重复改写 prompt 或建立大量标签文件。

当前最新决策：正式生成前，对 product-intent.md、design.md、component.md 进行单文件与跨文件 Spec Gate；通过只代表规格可执行。实现后仍需要同条件截图、行为与多端验收。

业务、参考、项目选择与验证结果分开。每个版本都要输出可读短 Query、自包含实现 Prompt、resolved 和素材包。query_only 模式交付后停止；build 模式再实现。

批次多样性先规划再生成，explore 产生独立方向，refine 保留各自视觉身份并局部修复。不能将多房型与单房源等不同业务分支当作同一需求的自由变体。

包内方案是整理稿，历史 source-snapshots 不自动代表已合并最新决策；外部路径不保证当前机器可访问。不要宣称本包包含完整聊天或外部项目实现。

先根据我本次明确任务选择阶段，不默认开始实现、重采参考、更新 skill 或推送 GitHub。若我要求实施，继续完成已授权工作，不只给计划。
```

## 尚未自动完成的事项

- 最新 Spec Gate/rubric 尚未因本次打包写入个人 skill。
- 本包不包含 webdev2/design-kb 及页面源代码。
- 历史页面验收不是此次重新运行结果。
- 对十页批次的感知差异阈值尚需实际页面校准。
