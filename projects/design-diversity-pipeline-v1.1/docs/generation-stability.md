# 生成稳定性：配方明确、资源真实、页面抗变化

稳定不表示十页长得一样。它表示每个方向在实现、加载、不同内容与屏幕条件下，仍符合自己的设计约定。

## 五种稳定性

| 类型 | 检查 | 不能混淆 |
|---|---|---|
| 输入稳定 | 配方、代码、依赖、字体/素材hash、数据、环境版本 | 随机换素材后截图不同不代表同一次复现失败 |
| 编译稳定 | 固定输入快照多次编译一致 | LLM重新自由设计不保证字节一致 |
| 布局稳定 | 断点、内容、状态、资源加载变化仍可用 | 只在1440截图正确不等于响应式通过 |
| 视觉身份稳定 | 字体角色、配色关系、构图节奏保留 | 不需要所有端像素完全一样 |
| 同站稳定 | 一方向多页面共享规则和语义 | 不要求不同方向共用同一结构 |

## Layout：先定规则，再定示例尺寸

记录container、box-sizing、padding、gap、列最小/最大宽度、区域顺序、sticky/fixed条件、滚动容器、z-index、错误内容扩展规则。正文可伸缩时说明谁收缩、谁换行，而非只列固定宽度。

每个区间测试下限、断点前后1px、至少一个中间宽度；design_basis只是示例。测试短屏与固定底栏、抽屉出现时的可达性。手机不假设等比例缩小。

压力内容包括长标题、中英文、长单词/链接、大价格、按钮标签、空列表、加载、缺货、错误与重试。200%文字/缩放可作为本项目压力测试，具体标准符合性需另按适用规则验证。不能裁掉必要标题来通过；要选择合理换行、展开或有完整可达信息的截断策略。

检查整页横向溢出并区分允许内部滚动的表格/图库。不要给body加overflow:hidden掩盖问题。数值容差要在运行前声明，例如几何量测的小数取整容差；不能容许真正遮挡。

## Font：声明、加载、实际呈现三件事

每个字体角色记录family、asset URL/path、version/hash、license、weight/style、可变轴、size/line-height/letter-spacing、字符范围、fallback及font-display策略。

检查流程：

1. 字体文件可获取且格式可解析；所需字重或可变轴存在，避免无意合成粗体/斜体。
2. 等待document.fonts.ready后进行稳定态截图，但该Promise只表示已用字体加载与布局操作结束；不证明指定字体被实际选用。
3. 结合FontFace状态、请求记录、字符样例、实际渲染字体检查（工具支持时）与视觉量测。computed font-family只是声明；document.fonts.check不能单独作为实际字体身份的证明。
4. 中文、拉丁、数字、标点单独查覆盖。没有中文字形时明确使用已选回退，不把系统替换当成原字体完整支持。
5. 冷加载、慢加载、文件失败时检查可读性和换行/高度变化；稳定态和加载期分别记录。
6. 替换字体后重新测标题行数、正文行长、按钮、导航与价格；不得只确认“看起来差不多”。

使用font-synthesis等控制时按字体资源与目标浏览器核验；不能靠禁止合成弥补缺失资源。字体身份锁定的是已选角色与关系，版本替换需记录适配。详见research/stability-sources.md。

## 图片、异步内容与Motion

图片按实际比例预留空间，记录object-fit/object-position；检查占位→加载、失败→回退和不同裁切。等待当前必要图片解码后拍稳定态，不能固定sleep代替就绪条件。

同时记录加载期布局变化：字体切换、图片无尺寸、价格更新、错误文案和sticky切换。CLS可作为诊断，不把某一次实验值当现场用户分位统计。涉及操作期的变化需检查焦点和点击目标，即便不计入某项CLS也可能影响使用。

动效按指定时间/状态截图；可暂停装饰性动效以比较静态布局，但真实动效另测。reduced-motion运行检查做不到时写partial/unknown，CSS规则存在不等于运行通过。

## 同站规则与方向隔离

共享业务模型、事件与无样式能力；每方向独立主题命名空间、布局组合及身份锁。同一方向首页/列表/详情继承语义token、字体角色、导航和交互约定。页面可以有不同布局，例外必须有内容理由。

检查路由切换是否泄漏另一方向的字体/token；浏览器返回和刷新状态是否符合约定。多方向同一应用时防止全局CSS选择器无意覆盖。

## 复现与稳定截图

记录浏览器/OS、viewport、DPR、locale、zoom、fixture、滚动位置、UI状态、字体/素材hash、依赖锁。固定构建重复加载确认身份与布局；不承诺不同OS字体抗锯齿逐像素一致。

资源就绪、状态稳定后记录连续量测；允许超时明确失败，不能无限等待。截图差异用于定位，不作为唯一质量结论。

## 完成标准

必需资源实际可用；要求的端、状态和内容样例通过；没有必要信息被裁切、不可达或关键操作漂移；身份与同站规则保持。尚未运行的浏览器、设备或语言明确列出。没有真实测试证据时只能说“规格已定义”。
