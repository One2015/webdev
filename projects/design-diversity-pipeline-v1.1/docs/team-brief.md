# 内部分享：同一业务，稳定做出不同网站

一句话：固定业务要求，写不同的网站配方，先确认做得好，再确认真的不同。

## 配方是什么

必须有的东西＋允许变化的东西＋素材条件＋验收标准。给人看简短设计要求，给制作模型完整说明，两份从同一份配方生成。

## 流程

固定业务 → 学习参考 → 写候选方向表 → 质量线筛选 → 看不同方向 → 按授权做小范围预览 → 锁定各方向特点 → 交付制作说明 → 实现 → 四张检查单 → 局部修复。

## 两条线

质量线：能用、合理、做得出来。差异线：整体表达有具体区别，不只是换图片或品牌。

## 稳定性

字体真的加载了吗？长标题会不会挤坏布局？换到手机、错误态、慢网后还能正常操作吗？同一个网站各页面有没有跑偏？

## 多样性

页面怎么组织、界面什么气质、图片怎么呈现。每两个选中方向都能说出实际区别；看最近的一对，不只看平均分。

## 四张检查单

功能完整、单页质量、同站一致、方向差异。

## 三个重点

候选表解决“方向怎么来”；提前预览解决“发现太晚”；特点锁定解决“修着修着一样”。共享业务逻辑，不强制共用布局。数量和权重是任务约定，不是行业标准。
